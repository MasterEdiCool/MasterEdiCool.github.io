# MasterEdiCool.github.io

Edison Chen's personal portfolio — a single-page site covering projects, bio, and contact info.

## Structure
- `index.html` — page layout and content
- `styles.css` — minimalist white/neutral theme, Inter font
- `script.js` — mobile nav toggle and year stamp

## Run locally
Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy
The repo is named `MasterEdiCool.github.io`, so pushing to the default branch publishes the site at https://masteredicool.github.io.

## Resume
Drop a `resume.pdf` in the project root to enable the "Download Resume" button on the Resume section.
