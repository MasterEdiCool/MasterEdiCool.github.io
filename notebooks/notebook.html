Mousey the Junkbot — Notebook

Latest entries at the top. Scroll down to read older entries.

  1. June 10, 2025 Finished

    Demo day — Mousey survives the hallway

    Final integration run. Mousey reliably follows a flashlight across the floor for ~3 minutes on a full charge before behavior starts to drift. Recorded the demo video and packed up for the showcase.

    Demo day photo
  2. May 22, 2025 Software

    State machine v2 — added "rest" mode

    Refactored control loop into a tiny FSM: SEEK → FOLLOW → REST → SEEK. Added a rest mode after 30 s of continuous motion so the motors don't overheat.

  3. April 4, 2025 Hardware

    Swapped phototransistor pair, fixed left/right bias

    The robot was consistently veering right. Turned out one phototransistor had a much lower gain than the other. Replaced with a matched pair from a dead optical mouse — now turns are symmetric.

    Phototransistor swap closeup
  4. February 15, 2025 Build

    First chassis from an old laptop shell

    Cut down a broken laptop bottom to use as the chassis. Mounted motors and wheels from a scavenged printer feed mechanism. Fits the breadboard with room for a second battery later.

  5. September 12, 2024 Kickoff

    Project kickoff

    Started Mousey. Goal: build a small autonomous robot using only e-waste and a single new Arduino. Sketched out the basic block diagram — sensors → microcontroller → H-bridge → motors.
